Start at the first regimen

Days before the first regimen are dropped. Each patient’s initial regimen, and whether it was twice daily, is that of regimen 1. Stata generated the value on regimen-1 days and used carryforward to copy it down; taking it from regimen 1 directly gives the same value on every row.

Click to show/hide R Code 
# Days before the first regimen are dropped. The first observation of a patient
# is the first day of regimen 1.
cohort_days <- analytic_days |>
  filter(!is.na(regimen_number)) |>
  left_join(baseline, by = "studyid") |>
  group_by(studyid) |>
  mutate(
    initial_regimen = first(regimen[regimen_number == 1]),
    initial_regimen_bid = first(bid_regimen[regimen_number == 1]),
    first_observation = day_in_regimen == 1 & regimen_number == 1
  ) |>
  ungroup()

cohort_flow <- count_patients(cohort_days, "Dispensed antiretrovirals in the study window")

Exclusions

In the order Final Analysis.do applies them, with the number of patients left after each, which is what a STROBE flow diagram reports.

One Stata habit needs care. drop if InitialRegimenBID drops rows where the variable is non-zero, and Stata treats a missing value as non-zero, so patients with a missing value are dropped too. A patient whose first regimen started before 2008 has no regimen-1 rows on the grid, so their value is missing and they leave here. Likewise drop if prevcareelsewhere drops patients with that field missing. The R filters keep only an explicit “no” (%in% FALSE, %in% 0) to match.

From the code: the exclusions for prior care elsewhere and missing insurance are not mentioned in the paper’s methods; the code is the record of what was done.

# In the order Final Analysis.do applies them. Stata's `drop if x` also drops
# patients whose x is missing, so each filter keeps only an explicit "no".
cohort_days <- cohort_days |> filter(initial_regimen_bid %in% FALSE)
cohort_flow <- bind_rows(cohort_flow,
                         count_patients(cohort_days, "Starting regimen taken once daily"))

cohort_days <- cohort_days |> filter(initial_regimen %in% manuscript_regimens)
cohort_flow <- bind_rows(cohort_flow,
                         count_patients(cohort_days, "Started one of the three compared regimens"))

cohort_days <- cohort_days |> filter(prior_care_elsewhere %in% 0)
cohort_flow <- bind_rows(cohort_flow,
                         count_patients(cohort_days, "No prior HIV care elsewhere"))

cohort_days <- cohort_days |> filter(!is.na(insurance_status))
cohort_flow <- bind_rows(cohort_flow,
                         count_patients(cohort_days, "Insurance status recorded"))

Exposure and time

The STR group is patients whose initial regimen is a single tablet; among the three compared regimens that is Atripla. Time zero is the first day of regimen 1. quarter is 0 for day 0, then 1 to 4 for days 1-91, 92-182, 183-273 and 274-364, and missing afterwards (Stata: egen Quarter = cut(DaysSinceARTInitiation), at(0,1,92,183,274,365) icodes). first_year marks days 0-364.

Click to show/hide R Code 
cohort_days <- cohort_days |>
  group_by(studyid) |>
  mutate(art_start_date = first(date[first_observation])) |>
  ungroup() |>
  mutate(
    str = initial_regimen %in% single_tablet_regimens,
    on_initial_regimen = regimen_number == 1,
    art_start_year = year(art_start_date),
    days_since_art_start = as.numeric(date - art_start_date),
    quarter = cut(days_since_art_start, breaks = quarter_breaks, right = FALSE,
                  labels = FALSE) - 1,
    first_year = !is.na(quarter)
  )

One row per patient

Stata kept the daily data and picked out each patient’s first day with if FirstObservationOfSubject on every command. R keeps a separate patient table, which is easier to read and to model. The baseline viral load and CD4 are the last values on or before the day ART started, with no limit on how long before.

Click to show/hide R Code 
# One row per patient, with the baseline viral load and CD4 as the last values
# on or before the day ART started.
patients <- cohort_days |>
  filter(first_observation) |>
  transmute(
    studyid, str, initial_regimen, art_start_date, art_start_year,
    age, male, black, hispanic, idu, msm, hepc, primaryriskfactor, ethnicity,
    insurance_status, had_psych_visit,
    baseline_vl = lvcf_vl, baseline_cd4 = lvcf_cd4
  )

Categories for the propensity model

Age, baseline viral load and baseline CD4 are put in the same groups as the Stata egen cut() lines. The insurance term in the propensity model, i3.Insurance, is an indicator for the third category in alphabetical order, because encode numbers text categories alphabetically. The paper describes this covariate as insured vs uninsured; which category is third depends on the categories in the real file.

Click to show/hide R Code 
# The propensity model used "i3.Insurance": an indicator for the third
# insurance category in the whole insurance file, in character-code order
# (insurance_categories, 02_labs_and_baseline.R). The paper describes this
# covariate as insured vs uninsured.
patients <- patients |>
  mutate(
    age_group = cut(age, breaks = age_breaks, right = FALSE),
    baseline_vl_group = cut(baseline_vl, breaks = vl_breaks, right = FALSE,
                            dig.lab = 8),
    baseline_cd4_group = cut(baseline_cd4, breaks = cd4_breaks, right = FALSE,
                             dig.lab = 8),
    insurance_category_3 = insurance_status == insurance_categories[3]
  )
