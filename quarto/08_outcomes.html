Retention in care

At least two viral loads in days 0-364, more than 90 days apart. Stata needed eleven lines: mark viral load days, blank out the rest, count them, multiply the indicator by the date to get measurement dates, take the minimum and maximum, subtract, and drop the helper variables. Filtering to first-year test days and summarising per patient says it in one step.

Click to show/hide R Code 
# HRSA definition: at least two viral loads in the first year after ART start
# (days 0-364), more than 90 days apart.
retention <- cohort_days |>
  filter(first_year, !is.na(current_vl)) |>
  group_by(studyid) |>
  summarise(
    first_year_vl_tests = n(),
    first_to_last_vl_days = as.numeric(max(date) - min(date)),
    .groups = "drop"
  )

Other outcomes

Each by studyid: egen x = max(...) or mean(...) in Stata becomes one line of a per-patient summarise(). any() is the R counterpart of max() over a 0/1 variable.

Every outcome uses the first year, days 0-364, as the paper describes: the data are filtered to first_year before summarising. This is a deliberate departure from the saved Stata. Its egen lines for suppression on the initial regimen, days covered and regimen change ran over every one of a patient’s days to the end of 2013, so a patient who started in 2008 would contribute up to six years and one who started late in 2011 two, and every day after a patient stopped filling would count as uncovered. The 2015 version of the same code limited the data to the first year first; the saved file lacks that step (details).

Click to show/hide R Code 
# Every outcome uses the first year after ART start (days 0-364), as the paper
# describes. The saved Final Analysis.do computes suppression on the initial
# regimen, the proportion of days covered and regimen change over all of a
# patient's days to the end of 2013, because its `by studyid: egen` lines have
# no first-year restriction; the 2015 version of the same code restricted the
# data to year one first. See the "Which file does what" page.
patient_outcomes <- cohort_days |>
  filter(first_year) |>
  group_by(studyid) |>
  summarise(
    vl_suppressed_year_one = any(vl_suppressed),
    vl_suppressed_on_initial_regimen = any(vl_suppressed & on_initial_regimen),
    proportion_days_covered = mean(day_covered),
    proportion_days_covered_initial = mean(day_covered & on_initial_regimen),
    changed_regimen = n_distinct(regimen_number) > 1,
    .groups = "drop"
  )

patients <- patients |>
  left_join(retention, by = "studyid") |>
  left_join(patient_outcomes, by = "studyid") |>
  mutate(
    retained_year_one = coalesce(first_year_vl_tests >= 2 &
                                   first_to_last_vl_days > retention_min_gap_days, FALSE),
    adherent_pdc_80 = proportion_days_covered >= pdc_adherent,
    adherent_pdc_80_initial = proportion_days_covered_initial >= pdc_adherent
  )

Counts and percentages by group, as in the tab outcome InitialRegimenSTR, row column chi2 lines.

Click to show/hide R Code 
outcome_names <- c("retained_year_one", "vl_suppressed_year_one",
                   "vl_suppressed_on_initial_regimen", "adherent_pdc_80",
                   "adherent_pdc_80_initial", "changed_regimen")

outcome_summary <- patients |>
  select(str, all_of(outcome_names)) |>
  pivot_longer(-str, names_to = "outcome", values_to = "achieved") |>
  group_by(outcome, str) |>
  summarise(patients = n(), achieved = sum(achieved, na.rm = TRUE),
            percent = 100 * achieved / patients, .groups = "drop")

Odds ratios

For each outcome, one unadjusted and one weighted logistic regression, collected in a table. In Stata each was a pair of lines repeated for every outcome:

logistic RetainedInCareFirstYear InitialRegimenSTR if FirstObservationOfSubject
logistic RetainedInCareFirstYear InitialRegimenSTR if FirstObservationOfSubject [pw=IPW]

A loop over outcome names keeps every result in one table instead of in a log file.

Click to show/hide R Code 
outcome_models <- list()
for (outcome in outcome_names) {
  outcome_models[[outcome]] <- bind_rows(
    odds_ratio_for_str(patients, outcome),
    odds_ratio_for_str(patients, outcome, weight = "ipw")
  )
}
outcome_models <- bind_rows(outcome_models)
