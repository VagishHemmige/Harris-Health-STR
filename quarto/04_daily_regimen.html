Keep patients with fills

Patients never dispensed antiretrovirals cannot be in the study. Step 6 in Stata cut the wide pharmacy file into about 147 files, one per fill number, because merging it in one go ran out of memory; Step 7 then merged them one at a time in a loop. R joins long tables and needs neither step.

Click to show/hide R Code 
# Patients who were never dispensed antiretrovirals are dropped. Stata Step 6
# split the pharmacy file into about 147 pieces only because the merge ran out
# of memory; a join does not need that.
daily <- person_days |>
  semi_join(regimen_episodes, by = "studyid")

Carry the regimen forward

Each regimen is placed on the day it started and filled down until the next one starts. new_regimen marks the start days. A regimen that started before 1 January 2008 is not on the grid, so those days have no regimen until the next start: exactly what the Stata did, since it only matched start dates that fell inside the window.

Click to show/hide R Code 
# Each regimen is placed on its start date and carried forward until the next
# one starts. Days before the first regimen in the study window have none.
daily <- daily |>
  left_join(regimen_episodes, by = c("studyid", "date" = "regimen_start")) |>
  mutate(new_regimen = !is.na(regimen_number)) |>
  arrange(studyid, date) |>
  group_by(studyid) |>
  fill(regimen, regimen_number, bid_regimen, .direction = "down") |>
  ungroup()

List the drugs on each day

Stata used split CurrentRegimen, parse(/) to make CurrentDrug1Name, CurrentDrug2Name and so on, and then every later calculation looped over the drug positions. Here each drug in the regimen is its own row, numbered by its position, so later steps can group by drug instead of looping.

Click to show/hide R Code 
# Stata split the regimen name at "/" into CurrentDrug1Name, CurrentDrug2Name ...
# Here each drug is a row, numbered by its position in the regimen name.
daily_drugs <- daily |>
  filter(!is.na(regimen)) |>
  select(studyid, date, regimen_number, regimen) |>
  mutate(drug_name = regimen) |>
  separate_longer_delim(drug_name, delim = "/") |>
  group_by(studyid, date) |>
  mutate(drug_position = row_number()) |>
  ungroup()

Mark dispense days

A drug in today’s regimen that was dispensed today counts as a 30-pill fill. A drug dispensed that is not in the current regimen does not count, which is how the original handled stray fills of old drugs.

Click to show/hide R Code 
# A drug in the current regimen that was filled that day counts as 30 pills.
dispensed_drugs <- fills |>
  distinct(studyid, date = dispense_date, drug_name = drugname) |>
  mutate(pills_dispensed = fill_size_pills)

daily_drugs <- daily_drugs |>
  left_join(dispensed_drugs, by = c("studyid", "date", "drug_name")) |>
  mutate(pills_dispensed = coalesce(pills_dispensed, 0))
