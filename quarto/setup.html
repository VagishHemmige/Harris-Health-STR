Packages

dplyr and tidyr do the data work that Stata did with generate, replace, by, egen, merge and reshape. readr replaces insheet, lubridate replaces date(x, "MDY"), and stringr handles the regimen names. survey fits the weighted logistic regressions; it gives the same kind of robust standard errors Stata reports after [pw=IPW].

Click to show/hide R Code 
library(dplyr)      # data manipulation
library(tidyr)      # fill(), separate_longer_delim()
library(readr)      # reading the source CSV files
library(stringr)    # text: drug names and regimen names
library(lubridate)  # dates
library(broom)      # tidy model output
library(survey)     # weighted (IPW) logistic regression with robust standard errors

Where the data come from

The analysis read six CSV extracts. In this repository they are read from data-synthetic/, made by R/synthetic/make_synthetic_data.R with the same column names and formats as the originals and entirely random values. Setting the environment variable STR_DATA_DIR would point the code elsewhere. There is no real data in the repository.

The manual regimen corrections are read from a separate file. The real ones name patients and dispensing dates, so they are not published; the synthetic folder holds a three-line example.

The study window

Stata stores dates as days since 1 January 1960. Step 5 created 2,192 rows per patient and set CurrentDate = N + 17531, so the first row is 17532, which is 1 January 2008, and the last is 31 December 2013. In R the window is written as two dates.

expand 2192
by studyid: generate N=_n
generate CurrentDate=N+17531

Drug lists

Three lists that were long replace ... if cdmdescription=="..." chains in Stata become data here: the pharmacy descriptions that reveal the real drug behind an “Experimental” or “Other” entry, the descriptions of twice-daily products, and the regimens of interest. Putting them in one place makes them easy to check against a formulary.

Thresholds

Every number a reader might want to change, named once. In the Stata these were typed where they were used (<=400, <=90, >=0.8).

Click to show/hide R Code 
fill_size_pills        <- 30    # every fill assumed to be 30 pills (30 days)
vl_suppression_main    <- 400   # copies/mL, assay limit in 2008
vl_suppression_later   <- 50    # copies/mL, sensitivity analysis for starts after 2008
lab_window_days        <- 90    # days a suppressed viral load counts for (see vl_suppressed_on_day())
pdc_adherent           <- 0.8   # proportion of days covered counted as adherent
retention_min_gap_days <- 90    # HRSA retention: two viral loads more than 90 days apart
missed_fill_days       <- 90    # days without a fill used to flag outside pharmacies

Category limits

Stata’s egen x = cut(y), at(...) puts each value in the interval that starts at or below it, and gives a missing value at or above the last limit. cut(..., right = FALSE) in R uses the same convention.

Click to show/hide R Code 
# Stata egen cut(), at(): each interval includes its lower limit, and values at
# or above the last limit are missing. cut(right = FALSE) does the same.
quarter_breaks <- c(0, 1, 92, 183, 274, 365)  # day 0, then four quarters of year one
age_breaks     <- c(0, 25, 35, 45, 55, 65, 100)
vl_breaks      <- c(0, 401, 1000, 10000, 100000, 1000000, 10000001)
cd4_breaks     <- c(0, 50, 100, 200, 500, 1000000)

//We create a variable which categorizes age:
egen AgeCategorical = cut( age), at(0, 25,35,45,55,65, 100) icodes label
tab InitialRegimenSTR AgeCategorical if FirstObservationOfSubject, row column chi2

//We create a variable which categorizes initial viral load
egen InitialViralLoadCategorical = cut( LVCFViralLoad ) if FirstObservationOfSubject, at(0, 401,1000,10000,100000,1000000,10000001) icodes label
tab InitialRegimenSTR InitialViralLoadCategorical if FirstObservationOfSubject, row column chi2
bysort studyid (CurrentDate): carryforward InitialViralLoadCategorical, replace

//We create a variable which categorizes initial CD4
