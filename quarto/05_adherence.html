5. Pills on hand and daily outcomes

This script counts the pills of each drug a patient has each day, decides whether the day is covered by the full regimen, and defines the daily “still in care” and “virologically suppressed” measures. It produces analytic_days, the R counterpart of Stata’s “Data Analytic file”, for 6. Cohort.

Number the days of each regimen

Stata’s variable M counts the days within a regimen: bysort studyid CurrentRegimenNumber (CurrentDate): generate M=_n. Day 1 of regimen 1 is the patient’s first observation, which becomes time zero later.

Count pills on hand

For each drug, pills on hand follow count_pills_on_hand(): +30 on a fill day, -1 each day, never below zero. The first day of each regimen starts from that day’s fill plus any pills of the same drug left the day before, from carry_over_pills().

Regimens are processed in order because of that carry-over: regimen 2’s first day needs regimen 1’s last day. Stata did the same with nested loops over regimen number, drug position and previous drug position:

forvalues Regim=2(1)$MaxNumberRegimens{
  forvalues counter=1(1)$SizeOfLargestRegimen {
    replace CurrentDrug`counter'PillsLeft= CurrentDrug`counter'CurrentDispense if ((M==1)&(CurrentRegimenNumber==`Regim'))
    forvalues j=1(1)$SizeOfLargestRegimen {
      replace CurrentDrug`counter'PillsLeft=max(0,CurrentDrug`counter'PillsLeft+CurrentDrug`j'PillsLeft[_n-1]-1) ///
        if ((M==1)&(CurrentRegimenNumber==`Regim')&(CurrentDrug`counter'Name==CurrentDrug`j'Name[_n-1])&(CurrentDrug`counter'Name~=""))
    }
    ...

In R, the loop is over regimen numbers only. Matching drugs between the last day of one regimen and the first day of the next is a join by drug name, and the day-by-day count runs within each patient, regimen and drug.

# Regimens are processed in order, because the first day of a regimen can take
# over pills of the same drug left from the day before, the last day of the
# previous regimen.
pills_by_regimen <- list()

for (episode in sort(unique(daily_drugs$regimen_number))) {
  episode_drugs <- daily_drugs |> filter(regimen_number == episode)

  previous_regimen <- pills_by_regimen[[as.character(episode - 1)]]
  if (is.null(previous_regimen)) {
    previous_day <- tibble(studyid = numeric(), drug_name = character(),
                           previous_pills = numeric())
  } else {
    previous_day <- previous_regimen |>
      group_by(studyid) |>
      filter(date == max(date)) |>
      ungroup() |>
      select(studyid, drug_name, previous_pills = pills_on_hand)
  }

  first_day <- episode_drugs |>
    filter(day_in_regimen == 1) |>
    left_join(previous_day, by = c("studyid", "drug_name"),
              relationship = "many-to-many") |>
    group_by(studyid, drug_position) |>
    summarise(start_pills = carry_over_pills(first(pills_dispensed), previous_pills),
              .groups = "drop")

  pills_by_regimen[[as.character(episode)]] <- episode_drugs |>
    left_join(first_day, by = c("studyid", "drug_position")) |>
    arrange(studyid, drug_position, date) |>
    group_by(studyid, drug_position) |>
    mutate(pills_on_hand = count_pills_on_hand(pills_dispensed, first(start_pills),
                                               fill_size_pills)) |>
    ungroup() |>
    select(-start_pills)
}

daily_drugs <- bind_rows(pills_by_regimen)

Is the day covered?

A day is covered when every drug in the regimen has pills on hand, partially covered when some do, and uncovered when none do. With one row per drug, these are all() and any() over the day’s rows; Stata needed a loop over drug positions for each.

Click to show/hide R Code 
# A day is covered when every drug in the regimen is on hand, partially covered
# when some but not all are, and uncovered when none are.
day_coverage <- daily_drugs |>
  group_by(studyid, date) |>
  summarise(
    day_in_regimen = first(day_in_regimen),
    number_of_drugs = n(),
    any_drug_dispensed = any(pills_dispensed == fill_size_pills),
    day_covered = all(pills_on_hand > 0),
    day_partially_covered = any(pills_on_hand > 0) & !all(pills_on_hand > 0),
    .groups = "drop"
  ) |>
  mutate(day_uncovered = !day_covered & !day_partially_covered)

Still in care and virologically suppressed

Still in care (lab-based): both a CD4 and a viral load are still to come. After a patient’s last test of either kind, they count as out of care.

Virologically suppressed: see vl_suppressed_on_day(). A viral load of 400 or less counts for 90 days; a day just before a suppressed result also counts if that result is within 90 days.

Click to show/hide R Code 
# Still in care: a CD4 and a viral load are both still to come. Virologically
# suppressed: see vl_suppressed_on_day() in functions.R.
analytic_days <- daily |>
  left_join(day_coverage, by = c("studyid", "date")) |>
  mutate(
    still_in_care_cd4vl = !is.na(days_until_next_cd4) & !is.na(days_until_next_vl),
    vl_suppressed = vl_suppressed_on_day(lvcf_vl, days_since_last_vl,
                                         days_until_next_vl, next_vl,
                                         vl_suppression_main, lab_window_days)
  )
