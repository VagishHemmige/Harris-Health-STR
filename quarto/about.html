About

Author

Vagish Hemmige

The study

Did starting HIV treatment on a single-tablet regimen, rather than three pills once a day, improve retention in care and viral suppression in the first year at a county safety-net clinic? Published as Hemmige et al. (2018). This site is teaching material: it explains the original Stata code and an R translation of it. The R has been run only on synthetic data.

  • Vagish Hemmige, Charlene A. Flash, Josephinel Carter, Thomas P. Giordano and Teddy Zerai (authors of the paper)

Scientific questions about the study go to Vagish Hemmige. Known issues are in Issues.

This repository

R/main.R runs the R scripts in order: five that build a one-row-per-patient-per-day data set from pharmacy and laboratory extracts, and four that select the cohort, weight it and compare outcomes. stata/ holds the original do-files. The real extracts are clinic records and are not in the repository; the code reads synthetic copies made by R/synthetic/make_synthetic_data.R.

Contributions follow the rules in AGENTS.md.

How this website was created

The site is built with Quarto from the scripts themselves. Each R code page imports the labelled sections of its script from R/ and shows them with an explanation; the Stata pages print the do-files from stata/. The site never runs the analysis, so it is built without any data.

The translation, the site and the documents were drafted with an AI assistant (Claude) using the R Analysis Workflow plugin, working from the do-files and the published paper and checked by running the R on synthetic data. The assistant had no access to the clinic data.

Four documents describe the project:

  • Analysis plan: what the analysis did, and why, reconstructed from the paper and the code, with the places they differ marked.
  • Architecture: how the R code does it. The scripts, their order, and the objects passed between them.
  • AGENTS.md: how people and AI assistants work on the project.
  • Repository blueprint: the layout every project of this kind starts from.
