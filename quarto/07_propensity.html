Propensity model

The covariates are those listed in the paper. In Stata, Gender was the numbered category made by encode (1 = F, 2 = M) entered as a number, which is the same model as a male indicator. Patients missing any covariate, for example with no viral load before ART, get no score and so no weight, and drop out of the weighted analyses, as they did in Stata.

One difference to know about: if a category predicts the regimen perfectly (every patient in it started the STR, say), Stata’s logistic drops that category and its patients with a note, so they get no score and no weight. glm() keeps them, warns that fitted probabilities are numerically 0 or 1, and reports a huge coefficient and standard error for that category. Those patients’ own weights are not large: each received the regimen predicted for them, so the weight is close to 1. The difference is who is weighted, so the two programs can give different results. Check for the warning before using the weights.

Click to show/hide R Code 
# The probability of starting an STR given the covariates listed in the paper.
# Patients missing any covariate get no propensity score and drop out of the
# weighted analyses, as in Stata.
propensity_model <- glm(
  str ~ hepc + male + black + hispanic + idu + msm + age_group +
    baseline_vl_group + baseline_cd4_group + insurance_category_3,
  data = patients, family = binomial()
)

Weights

Stata:

predict PropensityScore, p
generate IPW=(InitialRegimenSTR/PropensityScore)+(1-InitialRegimenSTR)/(1-PropensityScore)

The formula picks 1/p for STR patients and 1/(1-p) for the others; if_else() says so directly. These are average-treatment-effect weights.

Click to show/hide R Code 
# Inverse probability of treatment weights: 1 / P(STR) for STR patients and
# 1 / P(multi-tablet) for the others.
patients <- patients |>
  mutate(
    propensity_score = predict(propensity_model, newdata = patients, type = "response"),
    ipw = if_else(str, 1 / propensity_score, 1 / (1 - propensity_score))
  )

Weighted balance

Stata repeated the baseline tables with [aw=IPW]. Weighted means and proportions by group show whether weighting balanced the covariates; standardised differences are the usual summary.

Click to show/hide R Code 
# Stata repeated the baseline tables with [aw=IPW]. After weighting, the two
# groups should look alike on every covariate in the model.
weighted_balance <- patients |>
  filter(!is.na(ipw)) |>
  group_by(str) |>
  summarise(
    patients = n(),
    male = weighted.mean(male, ipw, na.rm = TRUE),
    black = weighted.mean(black, ipw, na.rm = TRUE),
    hispanic = weighted.mean(hispanic, ipw, na.rm = TRUE),
    idu = weighted.mean(idu, ipw, na.rm = TRUE),
    msm = weighted.mean(msm, ipw, na.rm = TRUE),
    hepc = weighted.mean(hepc, ipw, na.rm = TRUE),
    insurance_category_3 = weighted.mean(insurance_category_3, ipw, na.rm = TRUE),
    mean_age = weighted.mean(age, ipw, na.rm = TRUE),
    mean_baseline_cd4 = weighted.mean(baseline_cd4, ipw, na.rm = TRUE),
    .groups = "drop"
  )

Weighted balance by category

Stata also ran tab InitialRegimenSTR <variable> [aw=IPW], row for ethnicity, risk factor, age group, baseline viral load and CD4 groups, and insurance (lines 116-117 and 124-127). A loop over the variable names applies weighted_distribution() to each and stacks the results into one table, so the whole distribution can be compared between groups, not just the means.

Click to show/hide R Code 
# Stata also tabulated each categorical covariate with [aw=IPW]: ethnicity,
# risk factor, age group, baseline viral load and CD4 groups, and insurance.
# Weighted percentages in each category, by group.
balance_variables <- c("ethnicity", "primaryriskfactor", "age_group",
                       "baseline_vl_group", "baseline_cd4_group", "insurance_status")

weighted_categories <- list()
for (variable in balance_variables) {
  weighted_categories[[variable]] <- weighted_distribution(patients, variable, "ipw")
}
weighted_categories <- bind_rows(weighted_categories)
