1. Regimens from pharmacy fills

  • Show All Code

Author

This script turns the pharmacy dispensing record into each patient’s sequence of regimens, with the date each one started and whether it is taken twice daily. It produces fills and regimen_episodes for 4. Daily regimen.

Fix drug names and flag twice-daily products

Some fills were recorded as “Experimental” or “Other” though the product description shows the drug. A join to the lookup table in setup.R replaces six Stata replace lines. Each fill is also flagged if its product is taken twice a day: for example, darunavir 600 mg is the twice-daily dose, while 800 mg (two 400 mg tablets) is the once-daily dose.

R code 
fills <- fills_raw |>
  left_join(drug_name_fixes, by = "cdmdescription", relationship = "many-to-one") |>
  mutate(
    drugname = coalesce(fixed_drugname, drugname),
    dispense_date = mdy(medtransdate),
    bid_drug = cdmdescription %in% bid_descriptions
  ) |>
  filter(!is.na(drugname), drugname != "") |>
  select(studyid, dispense_date, drugname, cdmdescription, bid_drug)

Name the regimen on each fill date

The drugs filled on the same day, sorted alphabetically and joined with “/”, make that day’s regimen name. In Stata this took a reshape wide by drug, a loop to paste the names together, a string trick to trim trailing slashes, and a reshape long back:

bysort studyid DispenseNumber ( drugname) : generate M=_n
reshape wide drugname cdmcode cdmdescription cdpdrugcode drugconstituents BIDDrug , i( studyid DispenseNumber ) j( M)
generate CurrentRegimen=drugname1
forvalue i=2(1)$SizeOfLargestRegimen {
replace CurrentRegimen=CurrentRegimen+"/"+ drugname`i'
}

In R it is a grouped summary.

dispense_regimens <- fills |>
  group_by(studyid, dispense_date) |>
  summarise(regimen = make_regimen_name(drugname), .groups = "drop")

Apply manual corrections

The rule above fails when a patient picks up part of a regimen on its own day: Norvir and Truvada on Monday and Reyataz on Wednesday gives two short-lived “regimens”, Norvir/Truvada and Reyataz, and two spurious switches. The original analyst reviewed the patients whose sequences looked wrong and wrote 576 corrections, one replace line each, for the patient and date or date range. They name individual patients and dispensing dates, so they are left out of this repository (why). The code reads them from a file kept with the data; the synthetic example has three made-up rows.

Note how much of the Stata code these corrections were. A rule that merges fills a few days apart, or one that ignores a lone fill of a drug already in the regimen, might replace many of them, but would also be a different definition from the one published.

Recode early Complera

When Complera first came onto the formulary, some fills were recorded as Truvada. Once the corrections have set a fill date’s regimen to Complera, a Truvada fill that day is recoded.

R code 
# When Complera was new, some fills were recorded as Truvada. Once a fill date's
# regimen is Complera, a Truvada fill on that date is recoded as Complera.
fills <- fills |>
  left_join(dispense_regimens, by = c("studyid", "dispense_date"),
            relationship = "many-to-one") |>
  mutate(drugname = if_else(drugname == "Truvada" & regimen == "Complera",
                            "Complera", drugname))

Number the regimens

A new regimen starts on the first fill date and on any fill date whose regimen name differs from the one before. A regimen is twice daily if any fill within it was a twice-daily product. One row per regimen remains, with its start date; Stata kept the same by keep if NewRegimen and reshaped it wide with one column per regimen.

R code 
# A new regimen starts on any fill date whose regimen name differs from the
# previous fill date's. A regimen is twice daily if any fill in it is a
# twice-daily product.
regimen_episodes <- fills |>
  group_by(studyid, dispense_date, regimen) |>
  summarise(bid_dispense = any(bid_drug), .groups = "drop") |>
  arrange(studyid, dispense_date) |>
  group_by(studyid) |>
  mutate(
    new_regimen = regimen != lag(regimen, default = ""),
    regimen_number = cumsum(new_regimen)
  ) |>
  group_by(studyid, regimen_number) |>
  summarise(
    regimen = first(regimen),
    regimen_start = first(dispense_date),
    bid_regimen = any(bid_dispense),
    .groups = "drop"
  )

## Apply manual corrections

The rule above fails when a patient picks up part of a regimen on its own day: Norvir and Truvada on Monday and Reyataz on Wednesday gives two short-lived "regimens", `Norvir/Truvada` and `Reyataz`, and two spurious switches. The original analyst reviewed the patients whose sequences looked wrong and wrote 576 corrections, one `replace` line each, for the patient and date or date range. They name individual patients and dispensing dates, so they are left out of this repository ([why](stata_overview.qmd#privacy)). The code reads them from a file kept with the data; the synthetic example has three made-up rows.

Note how much of the Stata code these corrections were. A rule that merges fills a few days apart, or one that ignores a lone fill of a drug already in the regimen, might replace many of them, but would also be a different definition from the one published.

## Number the regimens

A new regimen starts on the first fill date and on any fill date whose regimen name differs from the one before. A regimen is twice daily if any fill within it was a twice-daily product. One row per regimen remains, with its start date; Stata kept the same by `keep if NewRegimen` and reshaped it wide with one column per regimen.
