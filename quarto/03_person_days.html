3. One row per patient-day

This script gives every patient one row for each day from 1 January 2008 to 31 December 2013 and attaches the lab results, with the last values carried forward and the days since the last and until the next test. It produces person_days for 4. Daily regimen.

Attach lab results

In Stata, with the labs in wide format, a loop checked every day against every test date:

generate CurrentCD4=.
quietly forvalues counter=1(1)$MaxNumberCD4Measurements {
replace CurrentCD4=CD4Result`counter' if CurrentDate==CD4Date`counter'
}

A join by patient and date does it directly. If a patient had two results on one day, the later one in the file wins in both versions.

Click to show/hide R Code 
# If a patient had two results on one day, Stata kept whichever its sort put
# last, which is arbitrary; here the last one in the file is kept.
cd4_by_day <- cd4 |>
  group_by(studyid, lab_date) |>
  summarise(current_cd4 = last(cd4), .groups = "drop")

vl_by_day <- viral_load |>
  group_by(studyid, lab_date) |>
  summarise(current_vl = last(vl), .groups = "drop")

person_days <- person_days |>
  left_join(cd4_by_day, by = c("studyid", "date" = "lab_date"), relationship = "one-to-one") |>
  left_join(vl_by_day, by = c("studyid", "date" = "lab_date"), relationship = "one-to-one")

}
drop VL*

Carry values forward and back

Stata counted days since the last test with a running sum (replace x = 1 + x[_n-1] if x==.), then sorted the data by negative date and repeated the trick to count days until the next test. tidyr::fill() carries a value down (or up) to the following missing rows, so the date of the last test and of the next test can be filled and subtracted from today’s date. The same fill gives the last value carried forward (LVCFCD4, LVCFViralLoad) and the next value (NextCD4, NextViralLoad).

Days before a patient’s first test have no “last” value; days after the last test have no “next” one. That second fact defines “still in care” in step 5.

Click to show/hide R Code 
# Last value carried forward (filled down) and next value (filled up), with the
# dates they come from, so that days since the last test and days until the
# next one can be counted. Before a patient's first test the "last" values are
# missing; after the last test the "next" values are missing.
person_days <- person_days |>
  mutate(
    last_cd4_date = if_else(is.na(current_cd4), as.Date(NA), date),
    last_vl_date = if_else(is.na(current_vl), as.Date(NA), date),
    lvcf_cd4 = current_cd4,
    lvcf_vl = current_vl,
    next_cd4_date = last_cd4_date,
    next_vl_date = last_vl_date,
    next_cd4 = current_cd4,
    next_vl = current_vl
  ) |>
  arrange(studyid, date) |>
  group_by(studyid) |>
  fill(last_cd4_date, last_vl_date, lvcf_cd4, lvcf_vl, .direction = "down") |>
  fill(next_cd4_date, next_vl_date, next_cd4, next_vl, .direction = "up") |>
  ungroup()

Count days between tests

The gap is the number of days between the tests either side of a day.

Click to show/hide R Code 
person_days <- person_days |>
  mutate(
    days_since_last_cd4 = as.numeric(date - last_cd4_date),
    days_since_last_vl = as.numeric(date - last_vl_date),
    days_until_next_cd4 = as.numeric(next_cd4_date - date),
    days_until_next_vl = as.numeric(next_vl_date - date),
    cd4_gap_days = days_until_next_cd4 + days_since_last_cd4,
    vl_gap_days = days_until_next_vl + days_since_last_vl
  ) |>
  select(-last_cd4_date, -last_vl_date, -next_cd4_date, -next_vl_date)
