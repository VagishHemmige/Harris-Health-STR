This script reads the CD4 and viral load results and the patient-level information: demographics, insurance, prior care and psychiatry visits. It produces cd4, viral_load and baseline for 3. One row per patient-day and 6. Cohort.

CD4 counts

Each Stata lab step read the file, converted the date, then reshaped to one row per patient with columns CD4Result1, CD4Date1, CD4Result2 … so that it could be merged one-to-one later. R keeps one row per test (long format) and joins by patient and date when needed, so no reshape is required.

//This file inputs the CD4 data from comma-separated variable files, and creates a wide format Stata data set with CD4s and dates obtained.

insheet using "Excel CD_4_DeID.csv", comma
drop testtype
rename resultnumeric CD4Result

//We convert the string dates to Stata format:
generate CD4Date=date( testdate , "MDY")
drop testdate

//Now, we create a wide format data set, saving the width in the Global $MaxNumberCD4Measurements
sort studyid CD4Date
by studyid: generate N=_n
quietly summarize N

reshape wide CD4Result CD4Date, i(studyid) j(N)
save "Data CD4 $DateOfAnalysis.dta", replace
clear

Demographics

Lower-case codes (f, m, b, h) are corrected, then indicators are made for the propensity model. Injection drug use and MSM each include the combined MSM&IDU category.

A blank ethnicity needs care. In Stata, generate Black=(ethnicity=="B") compares the blank text with “B” and gets 0, so the patient counts as not Black and keeps a propensity score. R reads a blank as missing, and ethnicity == "B" would give a missing value, which would drop the patient from the weighted analyses. ethnicity %in% "B" gives FALSE for a missing value, which matches Stata. In Stata, encode then turned the text into numbered categories “to save space”, which R does not need.

Click to show/hide R Code 
# Lower-case codes are corrected, and indicators are made for Black and Hispanic
# ethnicity, injection drug use and men who have sex with men. As in Stata,
# where `generate Black=(ethnicity=="B")` gives 0 for a blank, a missing
# ethnicity or risk factor counts as "no" rather than missing, so the patient
# keeps a propensity score.
demographics <- read_source_csv(data_dir, source_files[["demographics"]]) |>
  mutate(
    gender = if_else(gender %in% c("f", "m"), str_to_upper(gender), gender),
    ethnicity = if_else(ethnicity %in% c("b", "h"), str_to_upper(ethnicity), ethnicity),
    male = gender == "M",  # Stata entered Gender (F = 1, M = 2) as a number: the same if only F and M occur
    black = ethnicity %in% "B",
    hispanic = ethnicity %in% "H",
    idu = primaryriskfactor %in% c("IDU", "MSM&IDU"),
    msm = primaryriskfactor %in% c("MSM", "MSM&IDU")
  ) |>
  select(studyid, age, gender, male, ethnicity, black, hispanic,
         primaryriskfactor, idu, msm, hepc)

See it in context

//Flash single vs double data set
//Creates a Stata file with demographic characteristics
//12-16-2014 edition

clear

//First, we input the demographic information
insheet using "Excel Cohort_DeID.csv", comma

//We convert the date variables "IntakeDate" and "first_undetect_date" to Stata format
generate IntakeDate=date( intake_date , "MDY")
format IntakeDate %tdnn/dd/YY
drop intake_date
generate FirstUndetectDate=date( first_undetect_date, "MDY")
drop first_undetect_date
format FirstUndetectDate %tdnn/dd/YY

//We examine all of the predictors and clean up the variables a little bit.
//We also define the variables Black, Hispanic, IDU, and MSM based on the underlying variables
summarize age, detail
tab age, missing
tab gender, missing
replace gender="F" if gender=="f"
replace gender="M" if gender=="m"
tab ethnicity, missing
replace ethnicity="B" if ethnicity=="b"
replace ethnicity="H" if ethnicity=="h"
generate Black=(ethnicity=="B")
generate Hispanic=(ethnicity=="H")
tab primaryriskfactor, missing
generate IDU=( primaryriskfactor=="IDU" | primaryriskfactor=="MSM&IDU")
generate MSM=( primaryriskfactor=="MSM" |primaryriskfactor=="MSM&IDU" )

//Now, we encode Gender, Ethnicity, and RiskFactor variables as numbers, instead of strings, to save space:
encode gender, generate(Gender)
drop gender
encode ethnicity, generate(Ethnicity)
drop ethnicity
encode primaryriskfactor, generate(RiskFactor)
drop primaryriskfactor

//We save the dataset
save "Data Demographic $DateOfAnalysis.dta", replace
clear

Combine

Stata’s merge 1:1 keeps patients found in either file and records which in _merge; the Step 5 code listed the unmatched patients and then kept them all. full_join() does the same. A patient in the lab files but not in the demographics file is kept, with missing demographics.

merge 1:1 also stops if a patient appears twice in either file. check_unique_patients() does that check first, and relationship = "one-to-one" makes each join stop rather than duplicate a patient.

Click to show/hide R Code 
# Stata merged these files one to one and kept patients found in any of them,
# including patients with lab results but no demographic record. `merge 1:1`
# stops if a patient appears twice, so the same check comes first here.
check_unique_patients(demographics, "The demographics file")
check_unique_patients(insurance, "The insurance file")

baseline <- demographics |>
  full_join(distinct(cd4, studyid), by = "studyid", relationship = "one-to-one") |>
  full_join(distinct(viral_load, studyid), by = "studyid", relationship = "one-to-one") |>
  full_join(insurance, by = "studyid", relationship = "one-to-one") |>
  full_join(psych_visits, by = "studyid", relationship = "one-to-one") |>
  mutate(had_psych_visit = coalesce(had_psych_visit, FALSE))

//Flash-Zerai analysis
//This file creates the long version data set from demographic variables, CD4, and VL
//The data set created is "Data ExpandedCD4VLDemo $DateOfAnalysis.dta"
//12-16-2014 edition

//First, we open the data set with the demographic variables
use "Data Demographic $DateOfAnalysis.dta", clear

//Now, we add the CD4 variables, listing the observations who fail the merge (for whom there are no CD4 observations):
merge 1:1 studyid using "Data CD4 $DateOfAnalysis.dta"
tab studyid if _merge<3
drop _merge

//Now, we add the VL variables, listing the observations who fail the merge (for whom there are no VL observations):
merge 1:1 studyid using "Data VL $DateOfAnalysis.dta"
tab studyid if _merge<3
drop _merge

//Merge Insurance Data
merge 1:1 studyid using "Data Insurance $DateOfAnalysis.dta"
tab studyid if _merge<3

//Merge Psych visit data
